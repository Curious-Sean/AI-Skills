# AI-Skills

These skills are designed to push you towards active learning to let you use your brain.

[tutor](https://github.com/Curious-Sean/AI-Skills/tree/main/tutor): The default behavior that lets the AI ask questions rather than provide answers.

[didactics](https://github.com/Curious-Sean/AI-Skills/tree/main/didactics): The underlying principles of high quality teaching.

[teaching-diagrams](https://github.com/Curious-Sean/AI-Skills/tree/main/teaching-diagrams): Shows mermaid diagramms which map out core concepts and relationships visually.

[learning-goals](https://github.com/Curious-Sean/AI-Skills/tree/main/learning-goals): Asks the user about their learning goals seperately for each topic. ORL is an example topic
